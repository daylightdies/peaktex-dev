About ZIP code 77391

77391 is a PO Box ZIP code for Spring, TX, in Harris County. It does not appear in the Census Bureau's 2020 ZIP Code Tabulation Area (ZCTA) Gazetteer, which generally omits PO Box and unique ZIP codes that have no street-delivery area. The USPS preferred city is Spring; Klein is an accepted city name. This code is not a separate street-delivery business district.

If your business uses a 77391 PO Box, we serve you as part of Spring. Street-delivery service for the surrounding Klein and Spring community is covered on the Spring and Klein pages and on nearby street ZIP pages, including 77379.
